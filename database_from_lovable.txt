- required_points

Policy 1

Name: Anyone can view badges
Command: SELECT
Target: authenticated

Policy 2

Name: Admins can manage badges
Command: ALL
Target: authenticated
Expression: USING has_role(auth.uid(), 'admin'::app_role)

- id
- name

- description
- deadline
- created_at
- updated_at

Policy 1

Name: Anyone can view deadlines
Command: SELECT
Target: public
Expression: USING true

Policy 2

Name: Only teachers can manage deadlines
Command: ALL
Target: public
Expression: USING (EXISTS ( SELECT 1 FROM user_roles WHERE ((user_roles.user_id = auth.uid()) AND (user_roles.role = 'teacher'::app_role))))

table name: messages
- id
- user_id
- content
- created_at
- recipent_id

Policy 1

Name: Users can insert their own messages
Command: INSERT
Target: authenticated
Expression: CHECK (auth.uid() = user_id)

Policy 2

Name: Users can view relevant messages
Command: SELECT
Target: public
Expression: USING ((recipient_id IS NULL) OR (auth.uid() = user_id) OR (auth.uid() = recipient_id))

Policy 3

Name: Authenticated users can send messages
Command: INSERT
Target: public
Expression: CHECK (auth.uid() = user_id)

- id
- title
- artist
- url
- created_by
- created_at

Policy 1: Authenticated users can view music library

Command: SELECT
Applies to: public
Expression: USING (auth.role() = 'authenticated'::text)

Policy 2: Teachers can add to music library

Command: INSERT
Applies to: public
Expression: CHECK (EXISTS ( SELECT 1 FROM user_roles WHERE ((user_roles.user_id = auth.uid()) AND (user_roles.role = ANY (ARRAY['teacher'::app_role, 'admin'::app_role])))))

Policy 3: Teachers can delete from music library

Command: DELETE
Applies to: public
Expression: USING (EXISTS ( SELECT 1 FROM user_roles WHERE ((user_roles.user_id = auth.uid()) AND (user_roles.role = ANY (ARRAY['teacher'::app_role, 'admin'::app_role])))))
